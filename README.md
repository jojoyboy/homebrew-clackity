# Homebrew Tap for Clackity ⌨️✨

Official Homebrew Cask tap for [Clackity](https://github.com/jojoyboy/Clackityclack) — the featherweight, ultra-low-latency macOS menu-bar app for mechanical keyboard audio and cursor ripple effects.

## Installation

```bash
brew tap jojoyboy/clackity
brew install --cask clackity
```

Or install directly in a single command:

```bash
brew install --cask jojoyboy/clackity/clackity
```

## Updating

```bash
brew upgrade --cask clackity
```

## Uninstalling

```bash
brew uninstall --cask clackity
```
